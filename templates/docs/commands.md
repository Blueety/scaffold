# 命令说明

> 列出项目所有验证命令。Agent 完成修改后必须运行相关命令。

## 快速检查

| 命令 | 用途 | 什么时候跑 |
|---|---|---|
| `<test 命令>` | 单元测试 | 改了函数逻辑 |
| `<lint 命令>` | 代码风格 | 每次修改后 |
| `<typecheck 命令>` | 类型检查 | 改了类型定义或接口 |

## 完整检查

| 命令 | 用途 | 什么时候跑 |
|---|---|---|
| `<full test 命令>` | 完整测试套件 | 提交前 |
| `<build 命令>` | 构建 | 提交前 |
| `<e2e 命令>` | 端到端测试 | 改了用户流程 |

## 何时跑什么

| 改动类型 | 必须运行 |
|---|---|
| 单函数修改 | 针对性单元测试 |
| API 行为变更 | 相关集成测试 |
| UI 变更 | 构建 + 手动检查 |
| 认证/支付/数据迁移 | 完整检查 + 人工审查 |
