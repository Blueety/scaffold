# 方案对比对话模板

> 让 AI 帮你比较不同实现方案时用这个模板。
> 位置：**按需**，不算一个阶段。某处有几个方案拿不准时随时插进来，不必等讨论结束。

---

## 提问模板

```
我要实现 [具体功能]。

请给出 2-3 种实现方案，每种说明：
1. 核心思路
2. 需要改哪些文件
3. 优点
4. 缺点
5. 适合什么场景
```

## 追问模板

```
方案 A 和方案 B 对现有代码的影响哪个更小？
哪种方案更容易出 bug？
哪种方案以后维护成本更低？
如果项目规模变大，哪种方案更能扛？
```

## 让 AI 给推荐

```
综合考虑我的项目情况（[简述你的项目约束]），
你推荐哪个方案？为什么？
```

## 确认后压缩

```
我决定用方案 [X]。

请把这个决定压缩成一句话，写清楚：
- 选了什么方案
- 为什么选它
- 主要风险是什么

不要写代码。
```

> 输出落到 Task Handoff 的 `## 术语与决策 → 已排除的方案`（没选的方案 + 为什么不用），
> 以及 `## Risks`。满足 ADR 三条准入的（难以撤销 + 没背景会困惑 + 真实取舍）
> 另写 `docs/adr/NNNN-slug.md`。
