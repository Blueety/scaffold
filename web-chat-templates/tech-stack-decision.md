# 技术栈决策对话模板

> 在网页 AI 中讨论和确定技术栈时用这个模板。
> 位置：**project-kickoff 之后、frontend-design 之前**。也可以直接在聊天里问，不必走模板。

---

## 提问模板

```
我的项目需求：
- [简述项目]
- [核心功能]
- [特殊要求，如离线、实时、国际化等]

请推荐技术栈，包含：
1. 语言
2. 框架
3. 包管理器
4. 测试工具
5. 部署方式

每个选择说明：
- 为什么选它
- 主要替代方案是什么
- 什么情况下应该换
```

## 追问模板

```
这几个方案各有什么优缺点？
我这种规模的项目，哪个最省事？
如果以后要加 [某功能]，哪个框架扩展性更好？
哪个方案的学习成本最低？
```

## 对比表格模板

让 AI 输出对比表格：

```
请用表格对比这几种方案：
| 维度 | 方案 A | 方案 B | 方案 C |
|---|---|---|---|
| 开发速度 | | | |
| 学习成本 | | | |
| 社区生态 | | | |
| 扩展性 | | | |
| 部署复杂度 | | | |
```

## 最终确认

```
我决定用 [你的选择]。

请帮我确认：
1. 需要安装哪些依赖
2. 项目初始化命令是什么
3. 基本目录结构长什么样
4. 开发/测试/构建分别用什么命令

输出要简洁，我直接复制到终端执行。
```
